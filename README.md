# interp-eval

Interpretability-informed LLM evaluation platform. Detects sycophancy, refusal miscalibration, and ungrounded generation in LLM outputs using probing classifiers on hidden states — alongside deterministic and LLM-as-judge scoring.

> Status: under active development. See `docs/architecture.md`.

## Quickstart

\`\`\`bash
cp .env.example .env
make up
\`\`\`

Visit:
- Frontend: http://localhost:5173
- API: http://localhost:8000/docs
- Health: http://localhost:8000/health

## Development

\`\`\`bash
make install   # local Python deps via uv
make test      # run tests
make lint      # ruff + mypy
make format    # auto-format
\`\`\`
